### 续费会涨价吗？

不会。续费价和新购价保持一致，这一点和大量“首年低价、次年涨价”的商家正好相反，也是它适合长期持有的原因之一。

先在 KiwiVM 面板里用 Block List Check 检查 IP 是否被封，这是官方内置的检测工具。对在线率敏感的业务可以考虑 SLA 系列，除了 99.99% 在线率保障，每两周还能免费换一次 IP。
